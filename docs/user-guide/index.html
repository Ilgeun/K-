납품 지연·단종 시 대체 기자재를 선박 조건에 맞춰 검토하는 방법 — 5분 코스

앱 열기 (localhost:5173)
시작하기 전에1 선박2 요구조건3 후보4 비교·근거5 문서 업로드5-1 확정6 결과7 보고서새 선박자주 묻는 질문

이 서비스가 하는 일

대체 후보를 선박의 조건(선급·사용 계통·구경·재질 등)에 맞춰 걸러내고, 판정마다 원문 문서와 쪽수를 근거로 보여줍니다. 승인서에 문장으로 쓰인 사용 제한도 읽어서 반영합니다.

결과를 읽는 법

충족 현재 자료상 조건 충족
확인 필요 자료가 없어 확인이 필요
미충족 필수조건을 못 맞춰 제외
주의 조건부·특정 구성에만 해당하는 제한

AI · 규칙 · 사람의 역할

AI는 문서를 읽어 값과 사용 제한을 정리하고, 담당자가 원문과 대조해 확정하며, 규칙이 선박 조건에 대조해 판정합니다. AI가 판정을 대신하지 않습니다.

🚀 3분 체험 코스

  1. ① A호를 선택하고 ‘요구조건 보기’
  2. ② 인정 선급 체크박스를 바꿔 보기 (결과가 바로 바뀝니다)
  3. ③ 후보 3개 담기 → ‘비교 · 근거 보기’
  4. ④ ‘원문 · p.1’ 눌러 근거 확인
  5. ⑤ ‘문서 업로드’ → 샘플로 사용 제한 추출
  6. ⑥ 검토하고 확정 → 결과가 ‘제외’로 바뀌는지 확인
  7. ⑦ 검토 보고서 저장
1

선박을 고르거나 새로 등록하기

검토는 “어느 배의, 어떤 자리인가”에서 시작합니다. 선박마다 선급·사용 계통·필요 납기와 요구조건이 따로 저장됩니다.

  1. 1
    선택한 선박. 카드를 누르면 그 선박의 조건으로 바뀌고, 이후 모든 판정이 이 선박 기준으로 이루어집니다.
  2. 2
    + 새 선박 등록. 선박명·선급·사용 계통·필요 납기일을 입력합니다. (아래 ‘새 선박 등록’ 참고)
  3. 3
    교체 대상 기자재 변경. 부품 종류(밸브 4종), 기존 모델, 교체 사유를 바꿉니다. 후보는 여기서 고른 부품 종류의 제품만 나옵니다.
  4. 4
    삭제. 등록한 선박을 지웁니다. 마지막 1척은 지울 수 없습니다. 기자재 DB의 제품은 지워지지 않습니다.
  5. 5
    이 선박의 요구조건 보기. 다음 단계로 이동합니다.
  6. 6
    현재 선박 표시. 어느 화면에서든 지금 어떤 선박으로 작업 중인지 보이고, 누르면 선박 선택으로 돌아옵니다.
💡 팁 ‘사용 제한 대조 기준: 해수’는 이 선박의 사용 계통(해수 냉각)을 문서의 사용 제한과 맞출 때 쓰는 기준입니다.
2

요구조건 확인하고 고치기

선박에 등록된 조건이 자동으로 불러와집니다. 값을 바꾸면 바로 후보가 다시 판정되고 이 선박에 자동 저장됩니다.

  1. 1
    인정하는 선급. 여러 개를 고를 수 있습니다(하나 이상 필수). 선택한 선급 중 하나라도 유효한 형식승인이 있으면 충족입니다.
  2. 2
    필수 / 선택. 필수 조건을 못 맞추면 후보에서 제외되고, 선택 조건은 못 맞춰도 제외되지 않고 표시만 됩니다.
  3. 3
    값 수정. 예를 들어 구경을 150으로 바꾸면 결과가 즉시 달라집니다.
  4. 4
    수치·단위·필수조건 비교는 AI가 아니라 정해진 규칙으로 합니다.
  5. 5
    후보 탐색으로 이동합니다.
⚠ 알아두세요 납기는 기술 적합성과 따로 표시됩니다. 납기 값은 시연용 가상 데이터입니다.
3

후보를 분류해서 보기

등록된 제품을 요구조건으로 한 번에 대조해 충족 · 확인 필요 · 미충족으로 나눕니다.

  1. 1
    요약. 초록=현재 자료상 충족, 노랑=자료가 부족해 확인 필요, 빨강=필수조건 미충족(제외).
  2. 2
    탭. 검토 대상 / 충족 / 확인 필요 / 제외됨. 제외된 후보도 ‘제외됨’ 탭에서 사유를 볼 수 있습니다.
  3. 3
    종합 상태와 납기 배지. 납기는 기술 판정과 별도로 표시됩니다.
  4. 4
    항목별 결과. ✓ 충족, ✕ 미충족, ? 자료 없음. 자료가 없으면 추측하지 않고 ‘확인 필요’로 남깁니다.
  5. 5
    비교에 담기. 최대 3개까지 골라 다음 단계에서 나란히 비교합니다.
  6. 6
    + 제품 등록. 제조사 문서(PDF)를 올려 기자재 DB에 제품을 추가합니다.
💡 팁 ‘사용 제한(문서 기반)’이 ‘문서 미분석’인 후보는 제한 조건을 아직 읽지 않은 것이며, 제한이 없다는 뜻이 아닙니다.
4

나란히 비교하고 원문으로 확인하기

고른 후보를 항목별로 비교합니다. 모든 판정에는 어느 문서 몇 쪽인지 근거가 붙습니다.

  1. 1
    후보 선택 칩. 눌러서 비교 대상을 바꿉니다(최대 3개).
  2. 2
    후보별 종합 상태.
  3. 3
    원문 · p.N. 판정에 쓴 문서의 해당 쪽을 엽니다(아래 그림).
  4. 4
    사용 제한(문서 기반) 행. 문서에서 확정된 제한을 이 선박의 사용 계통에 대조한 결과입니다.
  5. 5
    납기 행. 기술 판정과 별도이며, 정보가 없으면 ‘공급사 확인 필요’로 표시합니다.
4-1

판정 근거 원문 보기

‘원문 · p.N’을 누르면 오른쪽에 근거가 열립니다. 실제 PDF가 있는 후보는 그 PDF의 해당 쪽이 표시됩니다.

  1. 1
    문서 정보. 어느 제품의 어떤 문서·몇 쪽인지 표시됩니다.
  2. 2
    강조된 줄이 판정에 실제로 쓴 원문입니다.
  3. 3
    닫기.
⚠ 알아두세요 이 그림은 가상 후보라 ‘가상 자료’ 형태로 보입니다. 실제 승인서를 올린 후보는 진짜 PDF 페이지가 열립니다.
5

문서를 올려 판정 바꾸기

‘확인 필요’인 후보에 필요한 문서를 올리면 사양·인증·사용 제한을 읽어 옵니다. 비교 화면 아래의 ‘문서 업로드 · 추출’을 누르세요.

  1. 1
    추출 방식. 자동(권장) / Claude API / Claude CLI / 규칙 기반. Claude CLI는 약 30초~1분, 계정 사용량을 소모합니다.
  2. 2
    내 PDF 올리기. 제조사 데이터시트나 선급 형식승인서(20MB 이하).
  3. 3
    샘플 문서로 시연. 실제 승인서 1건과 가상 샘플이 들어 있습니다. 가상 샘플에는 워터마크가 있습니다.
  4. 4
    추출 시작.
⚠ 알아두세요 Claude로 추출하면 문서 내용이 Anthropic으로 전송됩니다. 조선소 내부 자료는 보안 정책을 확인한 뒤 사용하세요.
5-1

추출 결과를 검토하고 확정하기 (가장 중요한 단계)

AI가 읽은 결과는 확정하기 전에는 판정에 쓰이지 않습니다. 원문과 맞는지 확인한 값만 확정하세요.

  1. 1
    추출 값과 현재 등록된 값을 나란히 봅니다. 체크한 항목만 반영됩니다.
  2. 2
    AI 해석 표시. 승인서의 제한 문장(“해수 계통 사용 불가” 등)을 읽고 금지·조건부·주의로 구조화한 결과입니다. 규칙 기반으로 추출하면 ‘규칙 기반 해석’이며 기본으로 선택되지 않습니다.
  3. 3
    수준 수정. AI가 잘못 분류했다면 사용 불가 / 조건부 / 주의 중에서 직접 바꿉니다.
  4. 4
    반영할 항목 선택. 틀린 해석은 체크를 끕니다. ‘⚠ 검증 필요’가 붙은 항목은 기본 해제되어 있습니다.
  5. 5
    원문 p.N. 근거 문장이 실제 문서에 있는지 눌러서 확인하세요.
  6. 6
    확인자 이름. 누가 확정했는지 기록됩니다.
  7. 7
    원문 대조 체크. 체크해야 확정 버튼이 활성화됩니다.
  8. 8
    확정 및 재평가. 반영하고 판정을 다시 계산합니다.
⚠ 알아두세요 AI 해석은 틀릴 수 있고, 같은 문서도 실행마다 결과가 다를 수 있습니다(실제로 같은 문서에서 사용 제한을 못 찾은 적이 있습니다). 그래서 ‘규칙 추출에서만 발견된 금지 조건’ 같은 경고가 나오면 원문을 꼭 확인하세요.
6

결과 확인하기

확정하면 판정이 즉시 바뀝니다. 아래는 “해수 계통 사용 불가” 제한을 확정한 뒤 해수 냉각 선박에서 본 결과입니다.

  1. 1
    종합 상태가 바뀝니다. 조건 충족이었던 후보가 ‘필수조건 미충족’으로 제외됩니다.
  2. 2
    사용 제한 행. ✕ 사용 불가와 함께 원문, 추출 방식, 확인자·시각이 남습니다.
  3. 3
    사용 제한 상세. 빨강은 제외 사유, 노랑은 ‘주의’(조건부·특정 구성 한정)입니다.
  4. 4
    원문 보기로 근거를 다시 확인합니다.
  5. 5
    내가 확정한 자료. 잘못 확정했다면 여기서 삭제하면 ‘확인 필요’로 되돌아갑니다.
💡 팁 같은 문서라도 선박의 사용 계통에 따라 결과가 달라집니다. 청수 냉각 선박에서는 ‘해수 사용 불가’가 해당되지 않아 이 후보가 그대로 충족으로 남습니다.
7

검토 보고서 저장하기

비교한 후보의 조건, 결과, 사용 제한, 미해결 항목, 근거 출처가 한 문서로 정리됩니다.

  1. 1
    PDF로 저장 / 인쇄. 브라우저 인쇄 창에서 ‘PDF로 저장’을 고르세요.
  2. 2
    후보별 비교 결과. 항목별 충족 여부와 근거 문서·쪽이 들어갑니다.
  3. 3
    사용 제한 검토. 제외 사유와 주의 사항이 원문과 함께 정리됩니다(확정된 제한이 있을 때만 표시).
  4. 4
    면책 문구. 사전 검토 지원 자료이며 최종 적용은 기술 검토와 선급 승인 절차를 거쳐야 합니다.
+

새 선박 등록하기

여러 척을 동시에 다룰 때 사용합니다. 기존 선박의 조건을 복제하고 선급과 필요 납기만 자동 조정됩니다.

  1. 1
    선박명(필수), 호선번호, 선종을 입력합니다.
  2. 2
    적용 선급과 사용 계통을 고릅니다. 사용 계통은 문서의 사용 제한과 대조하는 기준이 됩니다.
  3. 3
    추가로 인정하는 선급(선택). 주 선급 외에 이 선급의 승인도 인정합니다.
  4. 4
    필요 납기일. 오늘부터 이 날짜까지의 일수가 납기 조건이 됩니다.
  5. 5
    등록하고 선택. 등록하면 바로 요구조건 화면으로 이동합니다.
💡 팁 세부 조건(재질·구경 등)은 복제 원본을 따릅니다. 등록 후 ② 화면에서 고치세요.

자주 묻는 질문

화면의 후보와 납기는 실제 데이터인가요?

아닙니다. 후보 15개 중 실제 문서 기반은 1개(V15)이고 나머지 14개와 모든 납기는 시연용 가상 데이터입니다. ‘가상’ 표시가 붙어 있습니다.

확정하기 전에는 왜 판정이 바뀌지 않나요?

AI 추출은 틀릴 수 있어서, 담당자가 원문과 대조해 확정한 값만 판정에 씁니다. 확정한 사람과 시각이 기록됩니다.

‘문서 미분석’은 무슨 뜻인가요?

그 후보의 사용 제한 문구를 아직 읽지 않았다는 뜻입니다. 제한이 없다는 뜻이 아니며 판정에는 영향을 주지 않습니다.

같은 문서인데 사용 제한이 안 나올 때가 있어요.

AI는 같은 문서도 실행마다 결과가 다를 수 있습니다. 규칙 기반 검사가 찾은 금지 조건 후보가 있는데 AI가 못 찾으면 “규칙 추출에서만 발견된 금지 조건 후보” 경고가 나옵니다. 다시 추출하거나 원문을 직접 확인하세요.

잘못 확정했어요. 되돌리려면?

④ 비교 화면 아래 ‘내가 확정한 자료’를 펼쳐 항목을 삭제하면 ‘확인 필요’로 되돌아갑니다. 제품 자체를 지우려면 ③의 카드에서 삭제를 누르세요.

처음 상태로 되돌리고 싶어요.

화면 오른쪽 위 초기화를 누르면 시연 데이터로 돌아갑니다. 등록한 선박과 업로드한 문서도 함께 지워집니다.

Claude 추출은 비용이 드나요? 안전한가요?
  • Claude API 키가 있으면 API, 없으면 로그인된 Claude CLI를 씁니다. 둘 다 계정 사용량을 소모합니다.
  • 문서 내용이 Anthropic으로 전송됩니다. 내부 자료는 보안 정책을 확인하세요.
  • 둘 다 없거나 실패하면 규칙 기반 추출로 대체됩니다(정확도가 낮고 사용 제한은 기본 선택되지 않음).
